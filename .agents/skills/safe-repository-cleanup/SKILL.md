# Safe repository cleanup

An initial cleanup audit is non-mutating. Inventory candidates without inspecting environment secrets or uploaded document contents. Check imports, dynamic loading, routes, configuration, tests, docs, build scripts, symlinks, and available version history before calling a file unused. Filename similarity is not proof.

Classify confidence and provide an exact proposed deletion list. Delete only after the user explicitly authorizes that scope, then resolve the exact paths again and verify affected builds and tests. Protect migrations, lockfiles, configuration, security controls, fixtures, public assets, and user uploads unless explicitly named or approved.

Preserve unrelated work. State what was removed and whether Git or another backup can recover it.
